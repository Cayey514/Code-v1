EDITOR DE CÓDIGO HTML/CSS/JS CON VISTA PREVIA
---------------------------------------------

Un editor todo-en-uno para desarrollo web rápido que funciona directamente en tu navegador sin necesidad de instalación.

📂 CONTENIDO DEL PAQUETE:
- index.html      (Archivo principal)
- script.js      (Lógica del editor)
- styles.css     (Estilos visuales)

⚡ INSTRUCCIONES RÁPIDAS:
1. Abre el archivo index.html en cualquier navegador moderno
2. Escribe tu código HTML, CSS y JavaScript
3. Mira los resultados en tiempo real en el panel de vista previa
4. Usa el divisor para ajustar el tamaño de los paneles

🛠️ FUNCIONALIDADES PRINCIPALES:
- Tres pestañas de edición (HTML, CSS, JS)
- Resaltado de sintaxis profesional
- Vista previa automática al escribir
- Diseño adaptable (móvil/escritorio)
- Redimensionamiento de áreas

💡 CONSEJOS DE USO:
- Haz doble clic en el divisor para resetear los paneles
- Puedes editar el archivo styles.css para cambiar colores
- El código de ejemplo es tu punto de partida ideal

🚧 LIMITACIONES ACTUALES:
- No guarda automáticamente tu trabajo
- Falta autocompletado de código
- No incluye consola de errores
- Solo funciona con archivos locales

🔧 POSIBLES MEJORAS (para desarrolladores):
- Añadir guardado manual con localStorage
- Implementar sistema de archivos múltiples
- Agregar selector de temas de color
- Incluir snippets de código comunes

📜 LICENCIA:
Puedes usar, modificar y distribuir este editor libremente.
Es software libre para fines educativos y profesionales.

ℹ️ IMPORTANTE:
Este editor funciona completamente offline.
No requiere conexión a internet ni servidores.
